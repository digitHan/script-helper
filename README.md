# script-helper

유튜브 스크립트 작업을 돕는 웹 도구 모음.

🔗 **[사이트 바로가기](https://digithan.github.io/script-helper/)**

## 기능
- ✅ 한글 숫자 변환기 (음독·훈독 자동 구분)
- ⏳ 자막 글자수 체커 (예정)
- ⏳ SRT 분석기 (예정)

## 사용 예시
| 입력 | 출력 |
|---|---|
| `1968년` | 천구백육십팔년 |
| `32번째` | 서른두 번째 |
| `20살` | 스무 살 |

## 기술
